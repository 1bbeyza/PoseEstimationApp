# PoseEstimationApp

Android application for real-time human pose estimation with runtime model selection using multiple pose estimation models.

## Features

- Real-time pose estimation
- CameraX live camera pipeline
- Runtime model switching
- Skeleton overlay rendering
- Real-time FPS, inference time and confidence monitoring
- Performance statistics screen

## Supported Models

- MoveNet Lightning (TensorFlow Lite)
- MoveNet Thunder (TensorFlow Lite)
- MediaPipe Pose Landmarker
- RTMPose-S (ONNX Runtime)

## Technologies

- Kotlin
- CameraX
- TensorFlow Lite
- MediaPipe Tasks Vision
- ONNX Runtime
